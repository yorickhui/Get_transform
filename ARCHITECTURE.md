## 构建流程详解

### PyInstaller 构建过程

```
┌─────────────────────────────────────────────────────────┐
│ 1. 准备阶段                                              │
│    ┌──────────────────────────────────────┐            │
│    │ • 检查 Python 环境                    │            │
│    │ • 检查 PyInstaller                    │            │
│    │ • 读取 get_transform.spec            │            │
│    └──────────────────────────────────────┘            │
└─────────────────────────────────────────────────────────┘
                        ▼
┌─────────────────────────────────────────────────────────┐
│ 2. 分析阶段 (Analysis)                                   │
│    ┌──────────────────────────────────────┐            │
│    │ • 扫描 launch.py 及所有导入           │            │
│    │ • 识别依赖包（beautifulsoup4 等）     │            │
│    │ • 收集数据文件                        │            │
│    │ • 处理隐藏导入                        │            │
│    └──────────────────────────────────────┘            │
└─────────────────────────────────────────────────────────┘
                        ▼
┌─────────────────────────────────────────────────────────┐
│ 3. 打包阶段 (PYZ)                                        │
│    ┌──────────────────────────────────────┐            │
│    │ • 编译 Python 代码为字节码            │            │
│    │ • 压缩字节码                          │            │
│    │ • 创建 Python ZIP 归档                │            │
│    └──────────────────────────────────────┘            │
└─────────────────────────────────────────────────────────┘
                        ▼
┌─────────────────────────────────────────────────────────┐
│ 4. 可执行文件生成 (EXE)                                  │
│    ┌──────────────────────────────────────┐            │
│    │ • 嵌入 Python 解释器                  │            │
│    │ • 打包所有依赖                        │            │
│    │ • 添加引导加载器                      │            │
│    │ • UPX 压缩（可选）                    │            │
│    │ • 生成可执行文件                      │            │
│    └──────────────────────────────────────┘            │
└─────────────────────────────────────────────────────────┘
                        ▼
┌─────────────────────────────────────────────────────────┐
```

## 总结

### 核心设计原则

1. **模块化**: 每个模块负责单一功能
2. **跨平台**: 使用 pathlib 和平台工具抽象
3. **用户友好**: 提供多种使用方式
4. **自动化**: 构建和发布流程自动化
5. **文档完善**: 每个层次都有相应文档

### 关键技术

- **Python**: 核心语言
- **PyInstaller**: 打包工具
- **pathlib**: 跨平台路径处理
- **BeautifulSoup**: HTML 解析
- **JSON**: 配置持久化

### 扩展性

- ✅ 易于添加新功能（模块化设计）
- ✅ 支持新平台（platform_utils 抽象）
- ✅ 可集成 CI/CD（Makefile + scripts）
- ✅ 可添加 GUI（保留 CLI 接口）
