# Get_transform
这是一款Get笔记导出文件处理脚本，让导出的Get笔记命名不再是乱码，方便导入其他笔记软件

# 功能概述
GET笔记是一款优秀的国产AI笔记软件，在移动端收集小红书、抖音内容作为笔记体验非常优秀，但是他的导出功能比较弱，导出的为一串字符命名的html无法直接导入Notion等其他笔记。
为了方便自己同时使用GET和Notion笔记，方便在二者之间同步。我编写了这个脚本，有相同需求的同学可以复制使用


## 功能特性

- **自动目录初始化**: 首次运行自动创建所需目录结构（history/、new/、logs/），无需手动准备
- **智能路径检测**: 引导用户选择GET导出位置，支持自动扫描、ZIP解压、路径验证
- **依赖自动安装**: 启动时自动检查并安装缺失的Python依赖包
- **智能时间戳识别**: 自动解析文件夹名中的时间戳格式 (YYYYMMDDHHMM)
- **版本排序**: 按时间戳自动排序，识别最新和历史版本
- **重复文件检测**: 精确识别最新文件夹中与历史版本重复的文件
- **安全删除机制**: 提供试运行、备份、确认等多重安全保障
- **智能文件复制重命名**: 解析index.html中的标题映射，将HTML文件复制到指定目录并重命名为有意义的标题
- **友好的错误提示**: 对无效路径、权限问题提供详细错误信息和解决建议


## 使用方法

### 1. 快速开始（推荐）
**步骤1：下载并解压**
从Github下载Get_transform到你电脑任意本地文件夹

**步骤2：打开终端**
- Mac电脑：打开终端（Terminal）
- Windows电脑：打开PowerShell或命令提示符（CMD）

**步骤3：进入项目目录**
```bash
# 把下面地址替换成你的存放目录
cd "c:\Your_file\Get_transform"
```

**步骤4：运行启动脚本（推荐）**
```bash
python launch.py
```

**首次运行时，程序会自动：**
- ✅ 检查Python版本（要求3.6+）
- ✅ 自动安装缺失的依赖包（如beautifulsoup4）
- ✅ 自动创建必要的目录（history/、new/、logs/）
- ✅ 引导你选择或放置GET笔记导出文件

**或者直接运行主程序**
```bash
python duplicate_file_cleaner.py
```
> **注意**：直接运行主程序需要确保已安装Python 3.6+和beautifulsoup4依赖包。

### 2. 准备GET笔记导出文件

**方式1：首次运行时使用向导（推荐）**
运行程序后，如果history目录为空，程序会自动引导你：
1. 选择使用默认路径或输入自定义路径
2. 自动扫描并识别有效的GET导出文件夹
3. 支持直接指定ZIP压缩包，程序会自动解压
4. 自动复制导出文件夹到history目录

**方式2：手动放置**
1. 在GET笔记App中导出笔记（会生成ZIP压缩包）
2. 解压ZIP文件
3. 将包含`index.html`和`notes/`目录的文件夹复制到`history/`目录

**有效的导出文件夹结构：**
```
voicenotes_202510171604_getnotes_archive_xxx/
├── index.html          (必需：笔记索引文件)
└── notes/              (必需：笔记HTML文件目录)
    ├── xxxxx.html
    ├── xxxxx.html
    └── ...
```

**使用提示：**
- 首次使用时，history/中至少要有一个导出文件夹
- 如果history下只有一个文件夹，程序会将所有HTML重命名并保存到new文件夹
- 不要删除history中的历史版本，保留上次导出的笔记文件夹
- 有新笔记时，再次导出并放入history，程序会对比最新的2个文件夹，只将新增的笔记重命名

### 3. 操作选项

程序启动后会显示菜单：

```
请选择操作:
1. 试运行 (查看将要删除的文件，不实际删除)
2. 正式运行 (实际删除重复文件)
3. 仅复制重命名 (不删除重复文件，仅将最新文件夹中的HTML文件复制到new目录并重命名)
4. 退出
```

### 4. 推荐流程

1. **先运行试运行模式**：选择选项 `1`，查看将要删除的文件列表
2. **确认无误后正式运行**：选择选项 `2`，执行实际删除操作
3. **仅需复制**：如果只想复制重命名文件而不删除重复文件，选择选项 `3`
4. **选择是否备份**：正式运行时可选择是否创建备份

### 文件复制重命名功能
- **自动解析**: 读取最新文件夹中的index.html，提取笔记标题与文件名的映射关系
- **智能重命名**: 将HTML文件从哈希文件名重命名为有意义的标题
- **目标目录**: 复制到脚本所在目录下的 `new` 文件夹
- **文件名清理**: 自动处理特殊字符，确保文件名符合Windows文件系统要求

#### 示例
原文件: `9323c2f00816d6a7cfffabb9b8ea1ad5.html`
重命名为: `太变态！这个AI工具从写代码到发推啥都能干.html`


## 工作原理

1. **时间戳识别**：从文件夹名称中提取时间戳（格式：`voicenotes_YYYYMMDDHHMM_...`）
2. **版本排序**：按时间戳对文件夹进行排序，识别最新和旧版本
3. **文件对比**：比较各版本 `notes/` 目录下的文件名
4. **重复删除**：删除最新版本中与任何旧版本重复的文件
